How attribution works

Cloudflare bills at the account level, so nothing here is a per-app invoice. Every five minutes the collector reads usage from the GraphQL Analytics API and maps each Worker script, D1 database, R2 bucket, KV namespace, queue, Durable Object namespace, Vectorize index, Workers-for-Platforms dispatch namespace and AI gateway to an app using the patterns in the dashboard config. Each component's overage is priced at list rates and split in proportion to each app's share of its units. Resources that match no pattern land in Unattributed; infrastructure marked shared in the config is grouped under Shared / platform. Workers AI analytics carry no script name, so binding traffic is attributed by model.
